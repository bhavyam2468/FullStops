# FullStops. — Blog Reader 📖

**FullStops** is a distraction-free blog reader built as a single self-contained HTML page. It ships with a long-form blog and renders it in a dedicated reading experience.

## Features

- 📊 **Reading progress bar** — tracks your scroll position through the piece
- 🔠 **Reader typography** — monospace-accented design (JetBrains Mono), tuned line width and spacing for long reading sessions
- 🎨 **Dark / Light themes** — switchable, dark by default
- 🧭 **Scroll navigation** — smooth in-page navigation helpers
- ✍️ **Real content** — includes the author's own long-form writing, rendered cleanly

## Tech

- One `index.html` — HTML + CSS + vanilla JS, fonts via Google Fonts
- No framework, no build step

## Running

```bash
# just open index.html, or:
python3 -m http.server
```
